# PS Lounge 1.0

Локальное Windows-приложение для управления игровыми сессиями в PlayStation lounge.

Версия `1.0.0` фиксирует исходный рабочий продукт: оператор запускает и завершает сессии, контролирует занятость станций и выгружает данные для ежедневной работы.

## Возможности

- управление игровыми станциями и таймерами;
- старт, продление и завершение сессий;
- локальное хранение данных;
- резервная копия состояния на диске;
- выгрузка операционных данных в XLSX;
- сборка автономного Windows-приложения через PyInstaller.

## Стек

- Python 3 и Flask;
- vanilla JavaScript, HTML и CSS;
- openpyxl;
- PyInstaller.

## Запуск

```bat
run.bat
```

Приложение откроется по адресу `http://127.0.0.1:5000`.

## Сборка Windows-версии

```bat
build_exe.bat
```

Результат появится в `client_release\PS Lounge`.

## Версии

- `v1.0.0` — исходная стабильная версия;
- `v2.0.0` — восстановленная и расширенная версия с финансовым учётом, отчётами, настройками, восстановлением состояния, достижениями и усиленной проверкой данных.

Актуальная версия находится в ветке `main`.

## Лицензирование

Приложение использует офлайн-лицензию, привязанную к устройству. Приватные ключи, выпущенные лицензии и рабочие данные в репозиторий не входят.
